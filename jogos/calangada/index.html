CENÁRIO

Cada vez dura 45 s. Depois do tiro você tem 5 s para fugir (apertar FOGO de novo encerra a vez).
←→ anda · ↑↓ mira · segure e solte Espaço para atirar · Enter pula · Backspace pulo para trás
Tab/QE troca arma · 1–9, 0 escolhe · W ou clique direito abre o arsenal · F pavio da granada
Clique no mapa para mirar ali ou escolher o alvo (setas também movem o alvo) · arraste com o botão do meio/direito ou role a roda para olhar o mapa · P/Esc pausa · M som
Na tela: ◄ ► anda, ▲ ▼ mira, PULO (dois toques = pulo para trás), ARMA abre o arsenal, segure e solte FOGO (🎮 mostra/esconde). Toque no mapa para mirar ou escolher o alvo; arraste para olhar a ilha.
Controle de videogame: analógico/direcional anda e mira, A pula, B pulo para trás, X/RT segura e solta o tiro, Y arsenal, LB/RB troca arma, LT pavio, analógico direito olha o mapa, Start pausa.
