QUADRIX

Encaixe os blocos que caem e complete linhas inteiras para apagá-las. Quatro linhas de uma vez é um QUADRIX!

MODO

←→ move · ↓ desce rápido · Espaço derruba
↑/X gira horário · Z gira anti-horário · C/Shift HOLD
P/Esc pausa · M som
Na tela: botões (🎮 mostra/esconde). Toque rápido no poço gira; deslize para o lado move, para baixo desce, um peteleco para baixo derruba e para cima guarda a peça.
Controle de videogame: direcional move, A gira, B gira ao contrário, X/LB HOLD, ↑/RT derruba, Start pausa.
